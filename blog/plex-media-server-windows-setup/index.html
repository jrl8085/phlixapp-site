How to Install Plex Media Server on Windows — Step-by-Step

Published September 1, 2026 · 9 min read

Windows remains the most popular platform for running Plex Media Server at home. Whether you are repurposing an old desktop or dedicating a new machine, Windows 10 and 11 both make excellent hosts for Plex. This guide covers every step from downloading the installer to fine-tuning performance settings so your server runs reliably around the clock.

System Requirements

Before you begin, confirm your Windows machine meets these minimums:

  • Operating system: Windows 10 (64-bit) or Windows 11. Older versions like Windows 7 and 8.1 are no longer supported by Plex.
  • Processor: An Intel Core i3 or AMD Ryzen 3 handles direct-play streaming easily. For transcoding, you want an Intel Core i5 or better with Quick Sync support, or a discrete NVIDIA GPU.
  • RAM: 4 GB minimum, 8 GB recommended. If you plan to run other applications alongside Plex, 16 GB gives you comfortable headroom.
  • Storage: Plex itself uses minimal disk space, but metadata and thumbnails for large libraries can consume 10 to 50 GB. An SSD for the Plex database and an HDD or NAS for media files is the ideal combination.
  • Network: A wired Ethernet connection is strongly recommended for the server. Wi-Fi works but introduces latency and potential dropouts during streaming.

Step 1 — Download the Installer

Navigate to plex.tv/media-server-downloads in your browser. Select Windows from the platform list and download the .exe installer. The file is typically around 200 MB. Always download from the official Plex website to ensure you get the latest stable version with current security patches.

Step 2 — Run the Setup Wizard

Double-click the downloaded installer. If Windows SmartScreen displays a warning, click "More info" and then "Run anyway." The installer is digitally signed by Plex, Inc., so this warning is simply because the file was downloaded from the internet.

The setup wizard is straightforward. Accept the license agreement and choose your installation directory. The default location in C:\Program Files\Plex\Plex Media Server works well for most people. Click Install and wait for the process to complete. It usually takes under a minute.

When installation finishes, the wizard offers to launch Plex Media Server immediately. Leave this checked. Plex will start and automatically open the first-time setup in your default web browser at http://localhost:32400/web.

Step 3 — Claim Your Server

The first-time setup wizard prompts you to sign in with your Plex account. If you do not have one, create a free account at plex.tv. Signing in "claims" the server, linking it to your account so only you can administer it.

Give your server a recognizable name. This name appears in all client apps when selecting which server to connect to. Something like "Home Server" or "Office PC" works well. You can change it later in Settings under General.

Step 4 — Add Your First Library

The wizard walks you through adding media libraries. Click "Add Library," choose a type (Movies, TV Shows, Music, or Photos), and point it to the folder where your media files live. A few tips for this step:

  • Create separate libraries for each media type. Do not mix movies and TV shows in the same library.
  • If your files are on an external drive, make sure the drive letter is consistent. Windows sometimes reassigns drive letters after reboots, which breaks library paths.
  • For network drives, use a UNC path like \\NAS\Media\Movies rather than a mapped drive letter. UNC paths persist more reliably across reboots and service restarts.

After adding libraries, Plex begins scanning your files and downloading metadata. This initial scan can take anywhere from a few minutes to several hours depending on library size. Let it finish before judging results.

Step 5 — Configure Windows Firewall

Plex needs network access to serve content to your devices. The installer usually creates a Windows Firewall rule automatically, but it is worth verifying. Open Windows Security, go to Firewall and network protection, then click "Allow an app through firewall."

Look for "Plex Media Server" in the list. Make sure both Private and Public checkboxes are enabled. If Plex is not listed, click "Allow another app," browse to C:\Program Files\Plex\Plex Media Server\Plex Media Server.exe, and add it manually.

For remote access, you also need to forward port 32400 on your router. Log in to your router's admin panel and create a port-forwarding rule that directs external TCP traffic on port 32400 to your server's local IP address. After configuring this, go to Plex Settings, Remote Access, and click "Enable Remote Access." A green checkmark confirms it is working.

Step 6 — Run Plex as a Windows Service

By default, the Plex installer configures Plex Media Server to run as a Windows service. This means it starts automatically when Windows boots, even before anyone logs in. This is the recommended configuration for a dedicated server.

To verify, press Win + R, type services.msc, and press Enter. Find "Plex Media Server" in the list. Confirm that Startup type is set to "Automatic" and Status shows "Running." If it shows "Automatic (Delayed Start)," Plex will start a short time after boot, which is fine and can actually help avoid conflicts with other services during startup.

Running as a Desktop Application Instead

If you prefer to run Plex only when you are logged in, you can switch from service mode to application mode. Stop the Plex service in services.msc, set Startup type to Disabled, and then launch Plex Media Server from the Start menu. It will run as a tray application. To start automatically at login, add a shortcut to your Startup folder (shell:startup in the Run dialog).

Service mode is better for always-on servers. Application mode is better if you only want Plex running during specific sessions or if you have permission issues with network shares.

Step 7 — Prevent Sleep and Automatic Updates

A sleeping computer cannot serve media. Open Settings, then System, then Power and sleep. Set "When plugged in, put my device to sleep" to Never. For desktops, this is the only setting you need. For laptops acting as servers, also set the screen timeout separately since the screen can turn off without the system sleeping.

Handle Windows Updates Gracefully

Windows Update can restart your machine without warning, interrupting streams. To manage this, go to Settings, Windows Update, Advanced options, and configure Active hours to cover the times your household typically streams. Windows will avoid restarting during those hours. You cannot disable updates entirely on Home editions, but setting a broad active-hours window helps.

Performance Tips for Windows

Move the Database to an SSD

Plex stores its database, metadata, and thumbnail cache in %LOCALAPPDATA%\Plex Media Server. If this folder is on a slow HDD, browsing your library will feel sluggish. Move it to an SSD for significantly faster library loading and search. To relocate it, stop the Plex service, move the entire folder to your SSD, and then set the PLEX_MEDIA_SERVER_APPLICATION_SUPPORT_DIR environment variable to the new path.

Enable Hardware Transcoding

If you have a Plex Pass subscription and a compatible Intel CPU (6th generation or newer) or NVIDIA GPU, enable hardware-accelerated transcoding in Settings under Transcoder. This offloads video conversion to dedicated hardware, dropping CPU usage from near 100% to under 10% during transcoding. It is the single biggest performance improvement you can make on Windows.

Exclude Plex from Antivirus Scanning

Real-time antivirus scanning can slow down library scans and metadata downloads. Add the Plex data directory (%LOCALAPPDATA%\Plex Media Server) and the Plex installation directory to your antivirus exclusion list. In Windows Security, go to Virus and threat protection, Manage settings, Exclusions, and add both folder paths.

Disable Power Throttling

Windows 11 may throttle background processes to save energy. If Plex is running as a service, this can impact transcoding performance. Open Task Manager, find Plex Media Server in the Details tab, right-click it, and set Efficiency mode to Off. For a permanent fix, create a Power plan set to High Performance in the classic Control Panel.

Verifying Your Installation

Open a browser on another device on your network and navigate to http://YOUR-SERVER-IP:32400/web. If the Plex web interface loads and your libraries appear, your Windows installation is working correctly. Try playing a file to confirm streaming works end to end.

From here, install the Plex app on your phone, tablet, or TV and sign in with the same account. Your server should appear automatically on the local network.
