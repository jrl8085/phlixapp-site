How to Install Plex Media Server on Mac — Complete Guide

Published September 1, 2026 · 9 min read

Macs make excellent Plex servers. Apple Silicon chips deliver strong transcoding performance at minimal power consumption, and macOS is a reliable operating system for always-on services. Whether you are using a Mac Mini as a dedicated headless server or running Plex alongside your daily work on an iMac or MacBook, this guide walks through every step of the installation and configuration process.

Choosing the Right Mac

Any Mac running macOS Ventura (13) or later can run Plex Media Server, but some models are better suited than others:

  • Mac Mini: The best choice for a dedicated Plex server. Small, quiet, energy-efficient, and designed to run 24/7. The M-series Mac Mini consumes around 5-10 watts at idle, making it far cheaper to run than a desktop PC.
  • iMac: Great as a dual-purpose machine. Run Plex in the background while using the iMac for everything else. The always-on display is unnecessary for Plex but the hardware is more than capable.
  • MacBook: Works as a Plex server but has caveats. You need to prevent sleep when the lid is closed, battery health degrades when plugged in constantly, and the fan may run during transcoding. Use a MacBook only if it is your only option.
  • Mac Studio / Mac Pro: Overkill for Plex alone, but if you already own one for professional work, it handles Plex effortlessly alongside everything else.

Step 1 — Download and Install

Go to plex.tv/media-server-downloads and select macOS. Download the .dmg file. Once downloaded, double-click the DMG to mount it, then drag the Plex Media Server icon into your Applications folder.

Launch Plex Media Server from Applications or Spotlight. The first time you open it, macOS may display a security prompt asking whether you want to open an app downloaded from the internet. Click Open to proceed. You will also see permission requests for network access and possibly file access depending on where your media is stored. Grant all requested permissions.

When Plex launches, a small Plex icon appears in the menu bar at the top of your screen. This icon indicates Plex is running and provides quick access to open the web interface, restart the server, or quit.

Step 2 — Run the Setup Wizard

After launching Plex, your default browser opens to http://localhost:32400/web with the first-time setup wizard. Sign in with your Plex account to claim the server. If you do not have an account, create one for free at plex.tv.

Name your server something recognizable like "Mac Mini" or "Office iMac." This name appears in all client apps when selecting a server.

Step 3 — Add Media Libraries

Click "Add Library" in the wizard and choose a library type: Movies, TV Shows, Music, or Photos. Browse to the folder containing your media. For media on an external drive, navigate to /Volumes/YourDriveName/.

File Permissions on macOS

macOS enforces strict file permissions through System Settings. If Plex cannot access your media folder, you need to grant Full Disk Access or add Plex to the Files and Folders permissions. Go to System Settings, then Privacy and Security, then Full Disk Access, and add Plex Media Server. This is especially important for media stored in locations outside your home folder or on external drives.

If your media is on a network share (SMB or AFP), mount the share in Finder first, then point Plex to the mounted path under /Volumes/. For reliable automatic mounting, add the network share to your Login Items in System Settings under General.

Step 4 — Prevent Sleep

A sleeping Mac cannot serve media. This is the most common problem new Mac-based Plex users encounter. Configure your energy settings to prevent sleep:

Mac Mini and iMac (Desktop Macs)

Open System Settings, then Energy Saver (or Battery on laptops). Set "Prevent automatic sleeping when the display is off" to On. On a Mac Mini, also enable "Start up automatically after a power failure" so the server recovers from outages without manual intervention. The display can turn off to save energy without affecting Plex.

MacBook

If you must use a MacBook as a server, the challenge is preventing sleep when the lid is closed. Connect an external display or use a closed-clamshell setup with an external keyboard and mouse. Alternatively, use a utility like caffeinate in Terminal:

caffeinate -s &

This command prevents sleep for as long as the Terminal window stays open. For a permanent solution, create a Launch Agent that runs caffeinate at login. Be aware that running a MacBook closed and plugged in continuously will impact long-term battery health.

Step 5 — Configure the macOS Firewall

macOS has a built-in firewall that is disabled by default. If you have enabled it, you need to allow Plex through. Go to System Settings, then Network, then Firewall, and click Options. Add Plex Media Server to the allowed applications list and set it to "Allow incoming connections."

For remote access from outside your home network, forward port 32400 on your router to your Mac's local IP address. Then in the Plex web interface, go to Settings, Remote Access, and enable it. A green checkmark confirms that remote access is working.

Assign a Static IP

Port forwarding relies on your Mac having a consistent local IP address. By default, your router assigns IPs dynamically via DHCP, which means your Mac's address could change after a reboot. Fix this by either assigning a static IP in System Settings under Network, or by creating a DHCP reservation in your router's settings. The router method is generally preferred because it keeps network configuration centralized.

Step 6 — Start Plex Automatically at Login

You want Plex to launch whenever your Mac starts up. Open System Settings, then General, then Login Items. Click the plus button and add Plex Media Server from your Applications folder. Now Plex will start automatically every time you log in.

For a headless Mac Mini that nobody logs into, enable automatic login in System Settings under Users and Groups. Select your user account and enable "Automatically log in as." Combined with the Login Items setting, this ensures Plex starts after every reboot without manual intervention.

Step 7 — Optimize Performance

Apple Silicon Advantages

M-series Macs have dedicated media engines that accelerate video encoding and decoding in hardware. Plex supports hardware transcoding on Apple Silicon through VideoToolbox. This means an M1 Mac Mini can transcode multiple 4K streams simultaneously while barely increasing power consumption. Enable hardware transcoding in Plex Settings under Transcoder (Plex Pass required).

Storage Configuration

Keep Plex's metadata and database on your Mac's internal SSD for fast library browsing. Store actual media files on external drives if you need more capacity. USB-C and Thunderbolt drives provide the best performance. Avoid USB 2.0 drives, as their throughput is too low for reliable 4K streaming.

If using multiple external drives, consider creating a JBOD (Just a Bunch of Disks) configuration or using software RAID through Disk Utility. For simpler management, just add multiple folder paths to a single Plex library.

macOS Updates

macOS updates occasionally restart your Mac. Unlike Windows, macOS does not force-install updates during active use, but it does prompt regularly. Enable automatic updates but disable "Install macOS updates" if you want to control when restarts happen. Your Mac will still download the update but wait for your approval to install. Check for and apply updates during times when nobody is streaming.

Verifying Your Setup

From another device on your network, open a browser and navigate to http://YOUR-MAC-IP:32400/web. You should see your Plex libraries. Play a file to confirm streaming works. Then install a Plex client app on your phone or TV and sign in with the same account. Your Mac server should appear automatically.
