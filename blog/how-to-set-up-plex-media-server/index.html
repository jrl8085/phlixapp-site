How to Set Up Plex Media Server — Complete Beginner's Guide

Published September 1, 2026 · 10 min read

Plex Media Server turns any computer, NAS, or even a Raspberry Pi into a personal streaming platform for your movies, TV shows, music, and photos. If you have ever wanted your own private Netflix that works on every device in your house and remotely, Plex is the answer. This guide walks you through the entire process, from downloading the software to connecting your first client.

What You Need Before You Start

Before downloading anything, make sure you have the following ready:

  • A free Plex account. Sign up at plex.tv. You will use this account to claim your server and manage access.
  • A computer or NAS that stays on. Plex only streams when the server is running. A dedicated machine or NAS is ideal, but a desktop that is on most of the time works fine.
  • Media files. Movies, TV episodes, music, or photos stored locally or on an attached drive.
  • A local network connection. Ethernet is preferred for reliability, but strong Wi-Fi will work for initial setup.

Step 1 — Download Plex Media Server

Head to plex.tv/media-server-downloads and select your operating system. Plex is available for Windows, macOS, Linux (Ubuntu, Debian, Fedora, CentOS), FreeBSD, and most NAS platforms including Synology, QNAP, and Asustor.

Windows

Download the .exe installer and run it. The setup wizard will install Plex Media Server as a Windows service that starts automatically on boot. Once installation completes, a browser window opens to the setup wizard at localhost:32400/web.

macOS

Download the .dmg file, open it, and drag Plex Media Server into your Applications folder. Launch the app and you will see the Plex icon appear in your menu bar. The setup wizard will open in your default browser. To keep the server running after restarts, go to System Settings and add Plex Media Server to your Login Items.

Linux

For Ubuntu and Debian, download the .deb package and install with:

sudo dpkg -i plexmediaserver_*.deb
sudo systemctl enable plexmediaserver
sudo systemctl start plexmediaserver

For Fedora and CentOS, use the .rpm package with sudo rpm -i instead. Once the service is running, navigate to http://your-server-ip:32400/web in a browser.

NAS (Synology, QNAP)

On Synology, open Package Center, search for Plex Media Server, and install. On QNAP, use the App Center. Both platforms install Plex as a background package that persists across reboots. After installation, access the web interface through the NAS IP on port 32400.

Step 2 — Run the Setup Wizard

When you first access the Plex web interface, you will be prompted to sign in with your Plex account. This "claims" the server and links it to your account. Only the account that claims a server can administer it.

The wizard will ask you to name your server. Pick something descriptive like "Living Room PC" or "NAS." This name appears in client apps when selecting a server. You can change it later in settings.

Step 3 — Add Your Media Libraries

This is the most important step. Plex organizes content by library type, and each type has its own scanner and metadata agent. Click "Add Library" and choose the correct type:

  • Movies: One movie per folder or file. Plex matches filenames against TheMovieDB for posters, descriptions, and ratings.
  • TV Shows: Organized by show name, then season folders. Plex uses TheTVDB and TheMovieDB for episode metadata.
  • Music: Organized by artist, then album. Plex reads embedded tags (ID3, Vorbis) and supplements with MusicBrainz data.
  • Photos: Organized by date or event folders. Plex reads EXIF data from your images for dates, locations, and camera info.

Point each library to the folder on disk where your media lives. You can add multiple folders to a single library if your content is split across drives. Plex will scan the folders and begin downloading metadata automatically.

Proper file naming is critical. A file named The Matrix (1999).mkv will match correctly. A file named movie_rip_final_v2.mkv will not. See our guide on organizing your media library for Plex for naming conventions.

Step 4 — Configure Remote Access

By default, Plex only works on your local network. To stream when you are away from home, you need to enable remote access. Go to Settings, then Remote Access, and click "Enable Remote Access."

Plex will attempt to automatically configure your router using UPnP. If it succeeds, you will see a green checkmark. If it fails, you will need to manually forward port 32400 on your router. Our remote access setup guide covers port forwarding in detail.

Remote access also requires your server to have a public IP address. If your ISP uses CGNAT (Carrier-Grade NAT), direct remote access may not be possible without a VPN or relay service.

Step 5 — Connect Your First Client

With your server running and at least one library scanned, it is time to connect a client. Plex has apps for nearly every platform:

  • iOS and Android: Download the Plex app from the App Store or Google Play.
  • Apple TV: Install Plex from the tvOS App Store.
  • Smart TVs: Samsung, LG, and Vizio all have Plex apps in their app stores.
  • Web browser: Go to app.plex.tv and sign in.
  • Desktop: Plex has apps for Windows and macOS, or you can use the web player.

Sign in with the same Plex account you used to claim your server. The client will automatically discover your server on the local network. If you are remote and have configured remote access, it will connect through your public IP.

Step 6 — Optimize Your Settings

Once everything is working, there are a few settings worth adjusting:

Transcoding Quality

Under Settings, go to Transcoder. If your server has a modern Intel CPU with Quick Sync or an NVIDIA GPU, enable hardware-accelerated transcoding (requires Plex Pass). This dramatically reduces CPU usage when clients need transcoded streams.

Library Scan Schedule

By default, Plex scans for new files periodically. You can adjust scan intervals under each library's settings or trigger manual scans. For folders on local drives, you can also enable filesystem monitoring so Plex detects new files immediately.

Network Settings

Under Settings and Network, you can set a custom server port, restrict LAN networks, and configure bandwidth limits for remote streams. If you have a fast upload connection, you can allow original quality remote streaming. If your upload is limited, cap remote streaming quality to avoid buffering.

Common Setup Issues

Server not found by clients: Make sure the server and client are on the same network. Check that the Plex service is actually running. On Windows, check Services; on macOS, check the menu bar icon; on Linux, run systemctl status plexmediaserver.

Media not appearing after scan: Double-check your folder structure and file naming. Plex is strict about naming conventions, especially for TV shows. Ensure the library type matches the content type.

Slow metadata downloads: Large libraries can take hours to fully scan and download metadata on first setup. Let it run overnight. Subsequent scans are much faster because Plex only processes new or changed files.

What Comes Next

With your server set up and your first client connected, you are ready to start streaming. From here, you might want to explore sharing your library with friends and family, setting up a dedicated NAS for always-on streaming, or organizing your photo library in Plex.

The initial setup takes about 20 to 30 minutes. After that, Plex largely manages itself. Add new files to your folders, and they appear in your libraries automatically. It is one of the simplest self-hosted services you can run, and one of the most rewarding.
