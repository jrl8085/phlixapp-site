How to Set Up Plex Parental Controls

Published September 1, 2026 · 8 min read

A well-stocked Plex library is a wonderful thing, right up until your six-year-old discovers the horror movie collection. Plex includes a parental control system that lets you create restricted profiles for children, limit content by rating, lock certain libraries behind PINs, and prevent young users from accessing anything you deem inappropriate. This guide walks through every layer of protection Plex offers and how to configure them properly.

The Foundation: Plex Home and Managed Users

Plex's parental control system is built on top of Plex Home, which lets you create multiple user profiles under a single account. These are called "managed users" and they are the key to age-appropriate access.

Creating a Managed User

  1. Open the Plex Web app and click your avatar in the top right.
  2. Go to "Users & Sharing."
  3. Under "Plex Home," click "Create Managed User."
  4. Enter a name for the user (for example, your child's name).
  5. Optionally set an avatar so they can identify their profile on the user selection screen.

Managed users do not need their own email or Plex account. They exist entirely under your account and are fully controlled by you. When anyone in your household opens a Plex client, they see a profile selection screen where each managed user can choose their own profile.

How Many Managed Users Can You Have?

Plex Home supports up to 15 managed users on a Plex Pass account. Without Plex Pass, you get one managed user plus the main account. For most families, the Plex Pass limit is more than enough.

Content Rating Restrictions

The most powerful parental control is content rating filtering. You can restrict a managed user to only see content at or below a specific rating level.

Setting Rating Limits

  1. Go to "Users & Sharing" and select the managed user you want to restrict.
  2. Under "Restrictions," find the content rating settings.
  3. Set maximum allowed ratings for movies and TV shows independently.

For movies, the US rating system goes: G, PG, PG-13, R, NC-17. For TV, it uses: TV-Y, TV-Y7, TV-G, TV-PG, TV-14, TV-MA. You can set a managed user's maximum to PG for movies and TV-Y7 for television, for example. Anything above those thresholds becomes invisible to that user. They will not see it in search results, browse views, or recommendations.

What About Unrated Content?

This is an important edge case. If a file in your library does not have a content rating (because it was not matched or because the metadata source does not provide one), you can choose whether to allow or block unrated content for each managed user. The safe choice is to block unrated content for children's profiles, since the absence of a rating does not guarantee the content is appropriate.

International Ratings

Plex supports multiple rating systems. If your metadata uses UK ratings (U, PG, 12A, 15, 18) or other regional systems, you can configure restrictions accordingly. Make sure your library's metadata agent is set to the correct country so ratings are consistent.

Library Access Restrictions

Beyond content ratings, you can control which entire libraries a managed user can access. This is useful when rating-based filtering is not granular enough.

Restricting Library Access

  1. In the managed user's settings, look for "Library Access" or "Restrict Access."
  2. Uncheck any libraries you do not want the user to see.

For example, you might have a "Kids Movies" library and an "Adult Movies" library. Instead of relying purely on content ratings, you can give children access only to the Kids Movies library. They will never see the Adult Movies library in the sidebar, search, or anywhere else in the interface.

This approach is especially useful for content that does not have standardized ratings, such as home videos, music, or photos. You may not want your children browsing your entire photo library, for instance, so you can create a separate "Family Photos" library and restrict their access to just that one.

PIN Protection

Library restrictions and content ratings only work if people actually use the correct profile. Without further protection, a child could simply switch to the unrestricted admin profile. PINs prevent this.

Setting a PIN on Your Admin Account

Go to your account settings and set a PIN. This is a four-digit code required to switch to your profile on any Plex client in your Plex Home. Without the PIN, nobody can access your unrestricted view.

Setting PINs on Other Profiles

You can also set PINs on any managed user profile. This is useful for older teenagers who should not be able to switch to a younger sibling's profile (and vice versa), or for any profile that should not be casually accessible.

Requiring PIN for Profile Switching

When PIN protection is enabled, the Plex client's user selection screen will prompt for the PIN before switching to a protected profile. Unprotected profiles (like your child's restricted profile) can be selected without a PIN, making it easy for young kids to get to their content without help.

Sharing Restrictions

If you share your Plex library with friends or extended family, you can set restrictions on their access as well. When sharing a library with another Plex user, you can:

  • Limit which libraries they can access. Share only your Movies library but not your TV or Photos library.
  • Set content rating restrictions. Apply the same rating filters you would use for a managed user.
  • Control simultaneous streams. Limit how many concurrent streams a shared user can have.
  • Disable downloads. Prevent shared users from downloading content for offline viewing.

These restrictions are set per-user when you create or edit a sharing invitation under "Users & Sharing."

Building Age-Appropriate Profiles

Here is a practical setup for a family with children of different ages:

Profile: Young Child (ages 3 to 7)

  • Content rating cap: G for movies, TV-Y or TV-Y7 for TV
  • Library access: Kids Movies, Kids TV, Family Photos only
  • Block unrated content: Yes
  • PIN: None (make it easy for them to select their profile)

Profile: Older Child (ages 8 to 12)

  • Content rating cap: PG for movies, TV-PG for TV
  • Library access: Kids Movies, Kids TV, Family Movies, Family Photos
  • Block unrated content: Yes
  • PIN: Optional

Profile: Teenager (ages 13 to 17)

  • Content rating cap: PG-13 for movies, TV-14 for TV
  • Library access: All libraries except explicitly adult content
  • Block unrated content: No (teenagers can handle ambiguity)
  • PIN: Yes (prevent switching to admin profile)

Profile: Parent (admin)

  • No restrictions
  • PIN: Yes (four-digit lock to prevent children from accessing)

Limitations to Be Aware Of

Metadata accuracy matters. Plex's rating-based filtering only works if your media has correct ratings in its metadata. If a movie is missing its rating or tagged incorrectly, it may appear in (or be hidden from) the wrong profile. Periodically review your libraries for unrated or misrated content.

Plex's free ad-supported content. Plex Discover and the free streaming catalog can show content that is not part of your personal library. Managed user restrictions apply to these as well, but it is worth checking that the restrictions behave as expected for ad-supported content.

Third-party apps. Parental controls apply to the official Plex app. Third-party Plex clients may not respect managed user restrictions, since they authenticate differently. If your family uses a third-party player to access your Plex server, verify that it enforces the same content restrictions.

Profiles are not passwords. A technically savvy teenager who knows your Plex account credentials can access the admin panel through the web interface, bypassing managed user restrictions entirely. For true security, do not share your Plex account password with anyone.

Testing Your Setup

After configuring parental controls, always test them from the child's perspective:

  1. Switch to the restricted managed user profile in a Plex client app.
  2. Browse the library and verify that restricted content is not visible.
  3. Search for a specific R-rated movie or TV-MA show by name. It should return no results.
  4. Attempt to switch to the admin profile and confirm that the PIN prompt appears.
  5. Check the Discover tab to confirm that recommendations respect the content rating limits.

If anything appears that should not, revisit the managed user settings and double-check the content rating caps and library access permissions.
